## 一、整套工具由什么组成

整套系统 = 「生成器（kebiaomaker 手机APP）」 + 「生成产物（课表APK）」两层。

1. kebiaomaker（内农大课程表输出工具，包名 com.example.kebiaomaker）
   - 双 Tab：① 网页抓取器 ② 课表文件(HTML/MHT)解析生成
   - 内部内置：新版课表模板 index_template.html + 新版展示壳 template.apk
2. kebiao（课表展示壳，包名 com.example.kebiao，应用名可自定义如"25农水2课表"）
   - WebView 壳，加载 assets/index.html，提供 JS 桥、实时天气、提醒等原生能力
3. index_template.html（课表网页本体，kebiaomaker 生成时自动填数据）
   - 周课表 + 一键查询 + 结课小黑板徽章墙 + 实时天气场景 + 自定义工具沙盒

工作流一句话：手机抓取教务网页/导入 HTML/MHT → 一键载入解析 → 填应用名/头像 → 生成 APK → 一键安装，装出来的课表自带小黑板弹窗、实时天气、自定义工具。

## 二、kebiaomaker 生成器完整功能

### 2.1 文件载入（三种方式）
- 一键载入：自动扫描浏览器下载目录（Download 及 HonorBrowser/HuaweiBrowser/Baidu/QQBrowser/Quark/UCDownloads 等），找 .html/.htm/.mht 课表文件，多个时弹列表选择
- 手动载入：系统文件选择器任意选文件
- 自动扫描并解析：解析成功即自动填充，无需再点

### 2.2 解析能力
- MhtmlParser：支持 MHT 与 HTML 两种格式
  - parse()：解析 MHT（MIME 封装网页）
  - parseHtml()：解析纯 HTML（如教务导出页）
- 提取课程数据：课程名、周次(start-end)、单双周(parity)、节次、地点、教师、标签
- 附带学号/班级/学期等元信息

### 2.3 应用信息定制
- 应用名（桌面显示名）自由填写
- 可选自定义头像照片（生成时嵌进壳内）

### 2.4 生成 APK
- HtmlGenerator：把解析结果按占位符（__DATA_JSON__/__EXTRA_JSON__/__STU_ID__/__CLASS__/__TERM__）填进新版模板 → 完整课表 HTML
- ApkBuilder：以内置 template.apk 为壳，替换 assets/index.html 并打 label、头像，重建+对齐
- 产物保存到 Download，命名 = 应用名.apk

### 2.5 安装与交付
- 一键安装：走 FileProvider + 系统安装器（自动引导"允许安装未知应用"）
- 打开文件夹：定位到产物所在目录
- 全流程操作日志面板实时可见

## 三、课表展示壳 kebiao（原生能力）

### 3.1 JS 桥（window.KBNative）
- fetchWeather(cb)：原生子线程请求 wttr.in（已固定 Hohhot 呼和浩特，不再 IP 漂移），结果回调页面 window.__kbWeather(json)
- notifyNow(id,title,text)：即时系统通知
- scheduleReminders(json)：按课程安排批量设置课前提醒（AlarmManager + 广播 + 通知）
- 存/读提醒偏好持久化；到期自动弹通知

### 3.2 其它
- 加载 file:///android_asset/index.html，允许 JS，接口对页面开放

## 四、课表网页本体（新版模板）全部功能

### 4.1 周课表（主体）
- 多周次切换（下拉/左右箭头/点今天），周范围自动按 FIRST_MONDAY=2026-08-31 计算，共 17 周
- 按周筛选：全部/本周/单双周/指定周次
- 每日多节课卡片：课程名、地点、教师、讲课标签、颜色分类
- 课程时间轴（第一~四大节 08:00-18:15）、空课提示"本周无课"
- 班级/学号/学期抬头、图例
- 日期真实映射当前周（可"今天"直达）

### 4.2 一键查询（结课/剩余小黑板弹窗）
- queryAllRemaining：按真实当前时间统计全部 12 门课
- 弹窗 = 小黑板徽章墙 + 每门课"剩 X/总 节"列表
- 徽章模糊规则：blur=min(1, 剩余/总数)×3，越接近结课越清晰；归零 → 徽章点亮
- 弹窗样式：墨绿黑板+木框+彩色徽章，关闭按钮"知道了"
- 基准时间固定真实时间，不受自定义输入影响

### 4.3 结课小黑板（开屏/庆祝弹窗）
- autoGradCheck：打开 APP 即自动检测；每次打开都弹一次总览（当天去重，有新结课弹"恭喜"庆祝版，多门合并）
- 全部结课 = "全部点亮" 彩框特效
- 每门课专属 emoji 徽章 + 专属配色 + 真实总节数
- 弹窗带尾部 setTimeout 兜底，异常也强制弹，错误直接红字显示

### 4.4 天气场景（SVG 元素组合引擎）
- wxScene/codeToWx：实时 WMO 天气码 → 场景
- 元素：太阳 sunG、云 cloudG、雨 rainDrops、雪 snowFalls、冰雹 hails、雾 fogBands、风 windLines
- 粒子全黑板均匀散布（雨/雪/冰雹 x:6-256 全宽，不偏右），动画呼吸/飘落
- 天气标签 wx-tag：无椭圆框小灰字，贴黑板下方居中："呼和浩特 · 天气 · 温度"

### 4.5 自定义工具面板（页面最底部，沙盒隔离）
- 12 门课进度条：每门一行（不串行），range 0→该课总节数，拉 0 = 已结课绿✓
- ↺ 一键恢复真实剩余
- 12 种模拟天气按钮：晴/多云/阴/小雨/中雨/雷阵雨/雨夹雪/小雪/大雪/冰雹/雾/大风雨
- ↺ 一键恢复实时天气
- 🎯 预览小黑板：用"自定义剩余+模拟天气"渲染沙盒预览
- 沙盒原则：CUST_LEFT/CUST_WX 只影响自定义区内功能（openCustBoard source='cust'），主体开屏弹窗/一键查询/实时天气永远真实，互不污染
- 开放接口 gradStats() + CUST_LEFT/CUST_WX，供未来在框内扩展新功能复用

## 五、重要设计约定

| 项目 | 约定 |
|---|---|
| 数据来源 | 课表数据由生成器解析教务 HTML/MHT 注入，调整需重新生成 APK |
| 样式/布局 | 改模板 index_template.html 后重新生成即生效 |
| 生成器新功能 | 需改 kebiaomaker Java 代码重新打包 |
| 小黑板基准时间 | 一键查询/开屏检测用真实当前时间；模拟仅限自定义沙盒 |
| 天气城市 | 固定呼和浩特 Hohhot（wttr.in），不再 IP 定位 |
| 桌面名 | 生成时自定义，如"25农水2课表" |
| 首次周/周数 | FIRST_MONDAY=2026-08-31，MAX_WEEK=17 |
