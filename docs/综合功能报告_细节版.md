## 一、课表数据模型与算法细节

### 1.1 周次与时间基准
- FIRST_MONDAY = 2026-08-31，MAX_WEEK = 17
- getWeekOf(now)：按周一起始日期反推当前周序号；今天按钮 = 直达当前周
- 单双周 parity：0=每周，1=单周，2=双周；筛选器支持 全部/本周/单双周/指定周

### 1.2 节次时段表（PERIODS，分钟制）
| 节次 | 显示 | start | end |
|---|---|---|---|
| 第一大节 | 08:00-09:40 | 480 | 580 |
| 第二大节 | 10:05-11:45 | 605 | 705 |
| 第三大节 | 14:30-16:10 | 870 | 970 |
| 第四大节 | 16:35-18:15 | 995 | 1095 |

### 1.3 课程槽位与统计（gradStats）
- courseSlots(课程名)：把每门课的原始条目按（周次×单双周×是否当周已过）展开成"该课每一节"的时间槽
- 每槽含 endAt（该节课结束时刻）
- total = 槽位总数（=该课真实总节数，如普通物理学A2=34、大学体育3=17…）
- left = 槽位中 endAt 晚于 now 的数量；done = left<=0
- 结课判定完全以真实当前时间为基准；一键查询/开屏检测共享 gradStats

### 2.3 模糊规则（未结课徽章）
- f = min(1, left/total)；blur = round(f×3×10)/10 px；opacity = max(0.4, 1-blur×0.23)；saturate(0.7)

### 3.3 SVG 粒子参数（黑板坐标系 284×182）

## 五、壳子（kebiao / template.apk）原生接口细节

### 5.1 JS 桥 window.KBNative（addJavascriptInterface）
- version() → "kb1"
- fetchWeather(callbackVar)：异步线程拉天气→runOnUiThread→evaluateJavascript(`window.{cb}(json)`)
- requestPermission()：Android13+ 申请 POST_NOTIFICATIONS
- vibrate(ms)：震动
- notifyNow(id,title,text)：立即系统通知（测试用）
- scheduleReminders(json)：先 cancelAllInternal 再全量注册
- cancelAll()：清空全部提醒

### 5.2 提醒实现（AlarmManager）
- Reminder 结构：id / at(epochMs) / title / text
- scheduleList：每个提醒 setExactAndAllowWhileIdle → PendingIntent → ReminderReceiver
- 到点 Receiver：postNotification（id&0xFFFFFF 作通知id）+ 全屏 Activity 可选；持久化 SharedPreferences（savePrefs/loadPrefs），重启进程后 ReminderActivity 会恢复已存提醒重新注册
- 通知渠道：id 取 hash，title/text 直接展示

## 六、生成器（kebiaomaker）实现细节

### 6.1 目录扫描清单（autoScan/scanOnce）
- 固定目录：/storage/emulated/0/Download、/Download/HonorBrowser、/HuaweiBrowser、/Browser、/Quark、/Baidu、/QQBrowser、/UCDownloads
- 文件名含"课表/课程/class/kebiao"等关键词（keywords）才命中；扩展名第一轮 .html/.htm，第二轮 .mht
- 多个命中 → AlertDialog 列表选择；单命中直接自动载入

### 6.2 解析器
- MhtmlParser.parse(bytes)：解析 MHT 边界封装 → 提取正文表格
- MhtmlParser.parseHtml(bytes)：直接解析 HTML 表格（兼容教务导出页）
- 输出 ParseResult：courses[]（name/place/teacher/start/end/parity/day/period…）、stuId、className、term

### 6.3 HtmlGenerator.generate(result, 模板)
- 顺序替换 __DATA_JSON__/__EXTRA_JSON__/__STU_ID__/__CLASS__/__TERM__（esc 做 JSON 转义）
- 新版模板占位符与此完全一致 → 无需改 Java 代码即兼容新功能

### 6.4 ApkBuilder.build(ctx, html, appName, avatarBytes, dir)
- 读取内置 assets/template.apk（新版壳，含天气桥）
- rebuild：替换 assets/index.html；AndroidManifest/resources.arsc 中"课表"24字节 utf-16le 标签位改写成 appName；avatar 写资源；STORED 保留 manifest/arsc、其余 DEFLATED、CRC 重算
- 签名：apksigner --ks /root/build_apk/keystore.jks --ks-pass 123456 --ks-key-alias kebiao
- 产物：Download/<appName>.apk

### 6.5 安装交付
- 一键安装：FileProvider content://…fileprovider/apk/… + ACTION_VIEW + GRANT_READ_URI；未授权时引导 设置→允许安装未知应用
- 打开文件夹：DocumentsUI externalstorage primary 根目录（低版本回退 Toast 提示路径）
